ARP Guard

A host-based defense agent that detects ARP and DNS spoofing attacks in real time and automatically restores the victim machine's correct network state - turning a passive target into an active, self-healing endpoint.

Core objective

To build an endpoint agent that detects spoofing the moment it happens, automatically restores the correct network state without human intervention, and shows the entire fight live - with attacker attribution, blocking, and full audit logs.

Key concepts

ARP
The protocol devices use to find "who owns this IP" on a local network - has no built-in authentication.
ARP spoofing
An attacker sends forged replies claiming to be the router, redirecting the victim's traffic through them.
Trusted baseline
The router's real identity, verified once at clean startup - never re-derived from traffic that could be poisoned.
DNS spoofing
An attacker injects forged DNS responses from an untrusted source, redirecting lookups to malicious destinations.
Auto-block
If an attacker keeps spoofing continuously past a set duration, they're firewalled automatically - no click needed.
Per-attacker tracking
Every attacker is tracked by MAC across both attack types, so one attacker's activity never fragments across logs.

Honest limitations

Attacker IP attribution is heuristic for ARP - the forged packet only reveals the attacker's MAC, so their IP is learned via passive traffic and active subnet scanning.
Attacker hostname resolution is best-effort (reverse DNS / NetBIOS) and may show "Unknown" depending on the network.
Deauthentication detection requires monitor-mode-capable WiFi hardware not available in this build.
This protects the single endpoint it runs on, not the whole network.
